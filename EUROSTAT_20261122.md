# Eurostat в morning_upload

Процесс EurostatGasProcess включён в main.py строкой ("Eurostat", "run_eurostat").
Он вызывается ежедневно общим приложением и проверяет последний наступивший цикл
по EUROSTAT_RUN_DAY и EUROSTAT_TIMEZONE. Значения по умолчанию — 25 и Europe/Moscow.

## Отметка успешного цикла

Пример при сбое 25 ноября:
- 25 ноября — скачивание или отправка завершились ошибкой, отметка успеха не записана.
- 26 ноября — повторная попытка того же цикла за 25 ноября.
- 27 ноября — очередная попытка, если 26 ноября был сбой.
- После успешного сохранения CSV и отправки всем получателям фиксируется цикл 2026-11-25.
- В последующие дни процесс возвращает успешный пропуск.
- 25 декабря — начинается новый цикл.

Пример состояния state/eurostat_monthly.json:

    {
      "version": 1,
      "last_successful_cycle": "2026-11-25",
      "completed_at": "2026-11-27T08:02:00+03:00",
      "csv_file": "/app/output/eurostat/eurostat_gas_balance.csv",
      "rows": 15000
    }

Здесь rows и время приведены для иллюстрации. completed_at — фактическое время успеха.
Отметка публикуется атомарно после успешной отправки. Неудачная отправка тоже ведёт
к повторной попытке при следующем запуске. Повторный ручной запуск после успешного
завершения цикла будет пропущен.

Повторные попытки продолжаются до следующего 25-го и после смены месяца.
Когда наступит очередное 25-е, актуальным становится новый цикл, данные загружаются
одним общим окном. При первом запуске без файла состояния сразу выполняется
последний наступивший цикл. Например, 22 ноября выполняется цикл за 25 октября.
Так запуск после перерыва тоже получает актуальные данные.
Состояние хранится в каталоге state, уже монтируемом существующим run.sh.
Одновременные запуски защищены общей блокировкой проверки, скачивания, отправки
и записи отметки. Повреждённое состояние отражается ошибкой в журнале.

## Данные и CSV

Используется официальный SDMX-CSV API Eurostat для nrg_cb_gasm.
Данные проходят через DataGateway. Скачиваются все доступные статьи баланса
по природному газу G3000, месячная частота M, все страны и территории
с двухсимвольным кодом Eurostat. Агрегаты ЕС и еврозоны исключаются.
Названия и порядок столбцов исходного SDMX-CSV сохраняются.

По умолчанию единица MIO_M3 (млн м³), окно 24 месяца назад от текущего месяца.
Например, в ноябре 2026 года запрашиваются данные с ноября 2024 года.
Значение TJ_GCV выбирает энергетические единицы (ТДж по высшей теплоте сгорания).
Окно заново скачивается при каждом успешном цикле и заменяет итоговый снимок,
включая пересмотры Eurostat. Накопленной истории за пределами окна в этом процессе нет.

Результат output/eurostat/eurostat_gas_balance.csv записывается атомарно,
UTF-8 с BOM, разделитель ;. Он прикладывается к письму через общий mailer.
Десятичная точка, исходные значения, пустые наблюдения и флаги OBS_FLAG сохраняются.
Флаги m/p/e и неполный последний месяц допускаются как часть данных источника.
Ответы с ошибкой, пустые таблицы, неверная структура, даты, числовые значения
или повторяющиеся ключи приводят к неуспеху процесса и сохраняют прежний итоговый CSV.
В письме приводится последний месяц с числовыми данными по каждой стране.

Ключ наблюдения — freq, nrg_bal, siec, unit, geo, TIME_PERIOD.
Исходные колонки включают DATAFLOW, LAST UPDATE, freq, nrg_bal, siec,
unit, geo, TIME_PERIOD, OBS_VALUE, OBS_FLAG и CONF_STATUS.

Скачивание и SMTP имеют повторы по существующим правилам приложения.
После сбоя процесса повторная попытка выполняется следующим ежедневным запуском.
Новых Python-зависимостей не требуется.

## Установка

1. Распакуйте патч в корень morning_upload.
2. Добавьте нужные настройки из EUROSTAT_20261122.env.example в существующий .env.
3. Проверьте общий RECIPIENTS или заполните EUROSTAT_SUCCESS_RECIPIENTS.
4. Соберите morning_upload:latest существующим Dockerfile.
5. Обычный bash ./run.sh запускает приложение со всеми включёнными задачами.

common/monthly_process.py содержит переиспользуемую проверку ежемесячного цикла
и успешного завершения. Получение Eurostat находится в processes/eurostat/process.py.
В итоговом журнале ожидающие задачи имеют статус ПРОПУЩЕНО.
