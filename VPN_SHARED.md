# Общие параметры VPN/SSH

Единственный модуль реализации SSH-туннеля — `common/ssh_tunnel.py`. Все SSH-подключения используют один блок `VPN_SSH_*` и, для режима forward, `VPN_REMOTE_PROXY_*`. Настройки источников больше не переопределяют реквизиты SSH. Нет чтения прежних имён и механизма наследования между источниками.

Режимы источников:
- UEEX: `UEEX_TUNNEL_MODE=dynamic`, `UEEX_PROXY_ENABLED=true`, `UEEX_PROXY_URL=`.
- ChinaMoney: `CHINAMONEY_NETWORK_MODE=proxy`, `CHINAMONEY_TUNNEL_MODE=dynamic`, `CHINAMONEY_PROXY_URL=`.
- БелАЭС: `BELAES_NETWORK_MODE=auto`, `BELAES_TUNNEL_MODE=dynamic`.
- Open-Meteo: `TSKHINVAL_NETWORK_MODE=auto`, `TSKHINVAL_TUNNEL_MODE=dynamic`, `TSKHINVAL_PROXY_URL=`.
- DESFA (отключён): `DESFA_TUNNEL_MODE=dynamic`.

Для явного внешнего прокси сохраняются индивидуальные параметры PROXY_URL; это отдельный режим, не устаревший SSH-механизм. В dynamic временный SOCKS5 создаётся на свободном локальном порту самим приложением; Hiddify и постоянно открытый прокси-порт не нужны. Каждый процесс закрывает свой туннель. Проверка ключа SSH-сервера и TLS сохранена.

Обновление сервера: перенести значения действующих SSH-реквизитов в общий блок из `.env.example`, удалить индивидуальные SSH-переменные из рабочего `.env`, удалить прежний каталог `connection/` при обновлении поверх старой папки. Действующий приватный ключ переименовывать не нужно. Сохранить остальные реквизиты, state, output и logs. При Docker-запуске пересобрать образ. Архив не содержит рабочего `.env` или закрытого ключа. `gas_data_duty` не меняется.

Тесты сетевых маршрутов выполняются с имитацией туннелей/HTTP. В среде подготовки отсутствует Paramiko, при запуске тестов использовалась заглушка импорта этой библиотеки. Реальное SSH-подключение не выполнялось.
