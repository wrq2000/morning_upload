# Изменения относительно серверной основы

Основа — morning_upload_server.zip. Сохранены рабочие процессы БелАЭС,
Tuz Gölü, EPİAŞ и Docker/cron. УЭБ добавлена отдельной задачей с DataGateway,
CSV, Paramiko и основным/резервным SMTP. Сохранены серверные зависимости.

В последнем обновлении оставлен один режим УЭБ — окно UEEX_RECHECK_DAYS=14.
Каждый запуск запрашивает только окно календаря, объявлений и результатов.
История объединяется с обновлениями локально. Полные проходы и дополнительные
исторические ссылки исключены. Пустое окно разрешено; опубликованная сессия
без продаж/позиций учитывается как торги.

Удалены диагностические модули, тестовый shell-скрипт, методы проверки почты,
принудительный SMTP-профиль и демонстрационные блоки отдельных модулей.
Рабочие тела прежних классов и функций при удалении демонстраций сохранены.
Единственная точка входа Python — main.py без аргументов.

Состояние прежних запусков совместимо. CSV сохраняет 44 колонки; уведомления
о новых торгах, резервный SMTP и защита от повторной рассылки сохранены.
Dockerfile и requirements не менялись: тяжёлые слои используют кэш.
Постоянный output и действующий .env нужно сохранить.

Включение и отключение всех процессов объединено в ENABLED_PROCESSES (main.py).
УЭБ явно добавлена в список. Автоматическое добавление и переменные выбора
процессов удалены; run.sh использует список из собранного образа.
SMTP по-прежнему общий для всех процессов, с основным и резервным сервисами.
