# Обработчик результатов УЭБ, 23 ноября 2026

Старый адрес public/PublicHandler.ashx возвращает HTTP 404.
В актуальном js/PositionList.js биржа использует public/Handler/Action,
параметр команды называется name. Запрос результатов использует name=jResults.
Страница PositionList.aspx и структура ответа info/rows продолжают работать.

В патч включены следующие правки.
- processes/ueex/defaults.env — API_HANDLER=Handler/Action.
- processes/ueex/config.py — относительный путь обработчика с подкаталогом;
  прежнее значение PublicHandler.ashx автоматически переводится в Handler/Action.
- processes/ueex/sources.py — параметр name для нового обработчика.
- processes/ueex/processing.py — ссылки на документы public/Download?id=...,
  соответствующие текущему шаблону страницы.

Если в вашем .env явно указан UEEX_API_HANDLER=PublicHandler.ashx, он автоматически
заменяется при загрузке настроек с предупреждением. Можно записать
UEEX_API_HANDLER=Handler/Action в .env для использования текущего адреса.
Для прежних нестандартных обработчиков сохранён параметр CommandName.

CSV содержит 44 колонки. Перевод, исходные названия компаний и расчёт
actual_cost выполняются существующим обработчиком.
Общий HTTP-клиент сохраняет штатную обработку 404 как ошибки источника.

Установка в локальный morning_upload — распакуйте патч в корень проекта,
повторите обычный запуск main.py из PyCharm.
Для серверного Docker после замены файлов соберите morning_upload:latest.
Настройки SSH, ключи и файлы состояния хранятся в существующих пользовательских
.env, ~/.ssh и output. Патч содержит файлы кода и описание изменения.
Контекст промежуточного файла учитывает адрес API и обновится автоматически.
