# Обновление разметки УЭБ — 17 ноября 2026

Сайт www.ueex.com.ua перешёл на Next.js. Старый блок календаря `auctions-info`
отсутствует; вместо него используется `data-slot="day-auctions"`.
В объявлениях `main-content` может быть пустым контейнером для отложенного
HTML-фрагмента. Ссылки результатов находятся в `data-slot="auction-detail"`.

Парсеры выбирают новые блоки и поддерживают прежнюю разметку. Проверяются
дата календаря, номер сессии, адрес объявления и уникальность блока.
Оборванный HTML и страницы ограничения доступа завершаются явной ошибкой;
они не считаются успешной проверкой без торгов. При отсутствии нужного блока
ошибка содержит проверенные селекторы и заголовок ответа.

Публичный API PublicHandler.ashx / jResults сохранил формат info/rows.
На актуальных ответах проверены аукционы 2216577858 (4 позиции) и 2216577888
(2 позиции), названия компаний, 44 английских столбца CSV и actual_cost.

## Установка на сервере morning_upload

Распакуйте патч в `/home/vologzhaninov_as/projects/morning_upload/`
с заменой `common/html_tools.py` и `processes/ueex/parsers.py`.
Сохраните существующие `.env`, output, state и logs.

Пересоберите образ, поскольку исходный код копируется внутрь Docker:

```bash


cd /home/vologzhaninov_as/projects/morning_upload

docker build --progress=plain -t morning_upload:latest .


```

Обычный ручной запуск всех включённых процессов с рассылкой:

```bash


cd /home/vologzhaninov_as/projects/morning_upload

bash ./run.sh


```

Существующий cron продолжает вызывать тот же run.sh и образ morning_upload:latest.
Для применения исправления изменять cron не требуется. Диагностические и тестовые
модули в приложение не добавляются. Ошибки HTTP 502 и таймауты требуют отдельной
проверки доступности сайта и сетевого маршрута.
