# Даты в именах почтовых вложений — 23 ноября 2026

Для БелАЭС, УЭБ, СПбМТСБ и Eurostat имена вложений содержат дату и время создания CSV
в Europe/Moscow. Примеры:

- `belaes_2026-11-23_080000_123456.csv`
- `ueex_gas_export_2026-11-23_080000_123456.csv`
- `spimex_PCX1UGU036F_2026-11-23_080000_123456.csv`
- `eurostat_gas_balance_2026-11-25_080000_123456.csv`

Форматы и содержимое CSV не меняются. УЭБ, СПбМТСБ и Eurostat продолжают сохранять
рабочие файлы под прежними постоянными именами в `output/`. Для отправки делается
временная датированная копия с теми же байтами, после попытки отправки копия удаляется.
Дата берётся из mtime рабочего CSV, поэтому повторная доставка той же выгрузки использует
ту же дату. БелАЭС создаёт датированный временный файл сразу.

Имена остальных источников и переключатели `ENABLED_PROCESSES` не меняются.
Состояния отправки УЭБ, накопленная история СПбМТСБ, флаг месячного цикла Eurostat и
основной/резервный SMTP сохраняют прежнюю логику. Новых настроек `.env` не требуется.

В проект добавлен `common/csv_delivery.py`. Изменены:
`common/csv_process.py`, `processes/belaes.py`, `processes/ueex/process.py`,
`processes/spimex/process.py`, `processes/eurostat/process.py`.
Патч содержит только эти файлы и эту инструкцию. Полный архив — актуальная версия проекта.

После замены файлов на сервере необходимо пересобрать Docker-образ. Существующий cron
продолжает вызывать прежний `run.sh`; менять расписание сборщика не нужно.

```bash


cd /home/vologzhaninov_as/projects/morning_upload
docker build --progress=plain -t morning_upload:latest .


```

При ручном запуске выполняются все процессы, включённые в `main.py`, и отправляются письма:

```bash


cd /home/vologzhaninov_as/projects/morning_upload
bash ./run.sh


```

Почтовый обработчик должен сохранять исходное имя вложения в нужную входящую папку
отдельного проекта `gas_data_duty`. Загрузчик строит архив по дате из имени вложения.
Старые файлы без даты также принимаются, но с предупреждением и датой mtime.


Дополнение: датирование теперь включено также для Цхинвала и по умолчанию для всех
процессов CsvMailProcess. Имя каждого вложения фиксируется в логе mailer.
