# Вывозные таможенные пошлины — 25.11.2026 (МСК)

Публикующий орган — Минэкономразвития РФ; постановление Правительства РФ № 276 от 29.03.2013.
Официальный раздел (при проверке был недоступен):
https://economy.gov.ru/material/directions/vneshneekonomicheskaya_deyatelnost/tamozhenno_tarifnoe_regulirovanie/

Основной HTTP-источник — официальный сайт Минэкономразвития: прямой адрес по месяцу, затем поиск ссылки в профильном разделе. Поддерживаются HTML-таблицы и вложения DOCX/XLSX с подтверждённым периодом и датой. Если источник недоступен или документ не подтверждён, используются открытые полные тексты документов Минэкономразвития на Альта-Софт:
- https://www.alta.ru/laws_news/ (поиск ссылки на полный текст документа);
- https://www.alta.ru/tamdoc/last_month/ (резервный поиск в архиве документов).
Пример реального документа: https://www.alta.ru/tamdoc/26bn0202/ — от 26.10.2026,
период ноябрь 2026, нефть 0 USD/т, СУГ 61,5 USD/т. Позиция этан, бутан,
изобутан (2901 10 000 1, 55,3 USD/т) не загружается.

## Расписание (обновлено: текущий + следующий месяц)

Процесс включён в ежедневный запуск `main.py`. С 20-го числа (МСК) проверяет
текущий и следующий календарные месяцы. При первом запуске до 20-го числа
проверяет текущий месяц; если он уже был успешно отправлен в предыдущем цикле,
повторного опроса до 20-го числа нет. Если оба месяца доступны — один CSV из
четырёх строк. Если доступен только один — отправляет две строки сразу,
а недостающий месяц проверяет на следующих запусках, не повторяя уже отправленные
ставки. Ошибка источника не заменяется нулём. Успех полного цикла — только после
успешной отправки всех требуемых месяцев. После завершения цикла следующий опрос
начинается с 20-го числа следующего месяца. Источник поиска расширен архивом
https://www.alta.ru/tamdoc/all/ (ограниченная пагинация), если текущий документ
старше области поиска в архиве за последний месяц.

Состояние: `state/export_duty_monthly.json`, версия 2 с `cycle` и `sent_months`.
Старое состояние версии 1 читается, но намеренно не подавляет однократную
повторную проверку текущего месяца и (с 20-го числа) следующего. Файл состояния
обновляется атомарно только после подтверждённой отправки. Состояние сохранять
при обновлении. Пропущенные целиком прошлые месяцы не догружаются автоматически.

## CSV

`output/export_duty/export_duty.csv`, UTF-8 с BOM, разделитель `;`.
Вложение `export_duty_YYYY-MM-DD_HHMMSS_ffffff.csv` по МСК. Две или четыре строки (по две за каждый календарный месяц), дата начала и конца действия включительно. Ключ `product_code, date`.

| Поле | Содержание |
|---|---|
| date | Первый день месяца действия, ISO YYYY-MM-DD |
| date_to | Последний день месяца действия |
| product_code | CRUDE_OIL или LPG |
| description | Наименование позиции из документа |
| tnved_code | 2709 00 или 2711 12 - 2711 19 000 0 |
| value | Ставка, USD за метрическую тонну, число без округления |
| unit | USD/T |
| document_date | Дата документа, не дата действия ставки |
| source_url | URL полного текста документа |

Не подставляем ноль при пропуске данных. Проверяем заголовок и период документа,
коды ТН ВЭД, единицу USD за 1000 кг, обе числовые ставки. Нулевое значение —
нормальная ставка, если прямо указано в таблице. СУГ — общая позиция из документа,
включающая пропан-бутановую смесь; это не отдельная ставка для 2901 10 000 1.

## Настройки и проверки

Все новые переменные необязательны, приведены в `.env.example`. По умолчанию
используются общие `RECIPIENTS`, `ADMIN_RECIPIENTS` и HTTP-настройки. Новых
зависимостей нет. Если нужны отдельные получатели, задать `EXPORT_DUTY_SUCCESS_RECIPIENTS`.
Входящая папка на стороне gas_data_duty: `ExportDuty`.

`python -m unittest discover -s tests -v` — автономные проверки на HTML-фикстурах,
составленных по опубликованной таблице, с имитацией HTTP и SMTP. Сетевой запуск
в окружении пользователя не проверен; HTML может измениться. При ошибке разбора
цикл не отмечается успешным. Для первичного испытания можно запустить отдельно
`ExportDutyProcess().run()` из окружения с загруженным `.env`, либо общий `main.py`.

## Ручная проверка без отправки

Запустить `check_export_duty.py` из PyCharm в корне проекта. Он использует тот же
сетевой клиент и парсер, но независимо от расписания проверяет текущий и следующий
месяцы, печатает все колонки и формирует `output/export_duty/export_duty_check.csv`
при наличии подтверждённых данных. SMTP, БД и state не затрагиваются. При полном
отсутствии результата новый CSV не создаётся (старый проверочный файл не обновлён).
В журнале рабочего процесса также выводятся дата действия, товар, ставка, единица,
дата документа и ссылка. Настройки .env не меняются.

## Проверка приоритета источника

В `check_export_duty.py` можно установить `OFFICIAL_ONLY = True`: в этом режиме резервный источник не вызывается. Поле `source_url` показывает страницу, по которой подтверждены ставки. При отсутствии явной даты документа используется однозначная дата публикации официальной страницы. Реальная страница министерства в среде разработки не открылась; разбор проверен на искусственных HTML/DOCX/XLSX. PDF и старые бинарные DOC/XLS не поддерживаются и приводят к резервному поиску. Расписание, состояние и формат CSV не изменены.
