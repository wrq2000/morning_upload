# Словарь УЭБ и предупреждения — 18 ноября 2026

Словарь дополнен по четырём сессиям 13–17 ноября 2026 года (20 позиций):
условия экспорта и оплаты, пункт Ужгород / Вельке Капушаны, название договора.

Если перевода нет:

- известные фразы переводятся, неизвестные фразы сохраняются в исходном виде;
- неизвестное название документа сохраняется целиком без частичной замены;
- в журнал выводится WARNING с полем, исходным текстом и названием словаря;
- одинаковые предупреждения кэшируются в пределах процесса запуска;
- обработка продолжается, строки сохраняются в CSV и могут быть отправлены по почте.

Названия компаний сохраняются в исходном виде. Состав из 44 столбцов и расчёт
actual_cost остаются прежними. Сетевая и структурная проверка данных продолжает
действовать: послабление касается только отсутствующих переводов.

Проверено на Python 3.8 и 3.12: все 20 новых позиций и публикация CSV при
искусственно добавленных неизвестных условиях и названиях документов.

## Сервер morning_upload

Заменяется `processes/ueex/translations.py`. После копирования пересоберите образ:

```bash

docker build --progress=plain -t morning_upload:latest .


```

Обычный запуск всех включённых процессов с рассылкой:

```bash


cd /home/vologzhaninov_as/projects/morning_upload

bash ./run.sh


```

Сохраните существующие .env, output, state и logs. Изменять расписание cron
