# ChinaMoney — официальный USD/CNY

Ежедневный процесс, 10 календарных дней включая день запуска. Даты относятся к публикациям CFETS, не заполняются выходные. Официальный центральный паритет (CNY за USD), не рыночный спот.

Сборщик: `processes/chinamoney`, `main.py`, `CHINAMONEY_*` в `.env.example`. Ключ не нужен, TLS включён. Текущий JSON подтверждён веб-проверкой 25.11.2026 (6.7088); исторический GET описан сторонними разработчиками, реальный ответ не подтверждён. При отказе одного интерфейса отправляются доступные данные с предупреждением. При отказе обоих — ошибка без CSV-отправки. По умолчанию `CHINAMONEY_NETWORK_MODE=proxy`, `CHINAMONEY_TUNNEL_MODE=dynamic`, `CHINAMONEY_PROXY_URL=`. При пустом URL приложение само открывает временный SOCKS5 поверх SSH через Paramiko, используя общие `VPN_SSH_*` (включая путь к ключу и доверенный отпечаток/known_hosts). Отдельный Hiddify или постоянный SOCKS5 не нужен. Туннель используется для обоих HTTP-интерфейсов и закрывается до отправки письма. Явный `CHINAMONEY_PROXY_URL` имеет приоритет; `CHINAMONEY_NETWORK_MODE=auto` разрешает прямую попытку и резервный прокси, `direct` — только прямой маршрут. TLS и проверка SSH host key сохранены.

CSV UTF-8 BOM, `;`, поля date, currency_pair, value, unit, rate_type, source_url. Вложение `chinamoney_usdcny_*.csv`. На загрузчике папка `ChinaMoney`, архив `chinamoney/YYYY/MM/DD`. Таблица `"134101_schema".chinamoney_fx` создаётся автоматически. Ключ date, currency_pair, rate_type; старые файлы не перезаписывают свежие данные. Общая транзакция и журнал без изменений.
